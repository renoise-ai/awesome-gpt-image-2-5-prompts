## 🤔 What is GPT Image 2.5?

**ChatGPT Images 2.5** is OpenAI's image model released on **September 8, 2026**. Inside ChatGPT there is no model picker — you generate an image and you are using it. In the API it ships as **two** models: **GPT-Image-2.5 Flare**, the fast one, and **GPT-Image-2.5 Sunburst**, the higher-quality one. There is no single model called `gpt-image-2.5`.

**What changed versus GPT Image 2 — control, not size:**

* ✏️ **Precision editing** — edits touch only what you asked for
* 🔁 **Multi-turn edits** hold up instead of drifting over rounds
* 🧍 **Reference fidelity** — subjects stay recognizable
* ⚡ **Up to 50% faster**

**What did not change:** still up to 4K, still up to 16 reference images, same 1:3 to 3:1 aspect range. OpenAI claims no improvement to text rendering.
